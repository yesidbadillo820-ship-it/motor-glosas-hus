# Guía para sesiones de Claude Code — Motor de Glosas HUS

## Memoria común: BITÁCORA (obligatorio)

- **Al iniciar cualquier sesión, lee primero `BITACORA.md`.** Ahí está el resumen de
  todo lo trabajado, lo que quedó pendiente y lo que sigue.
- **Al terminar la sesión, actualiza `BITACORA.md`** agregando: lo que se hizo hoy, lo
  que quedó pendiente y lo que sigue mañana, **con la fecha**.

`BITACORA.md` es la memoria compartida entre todos los chats. Manténla en lenguaje
claro y sin tecnicismos: la lee personal de Cartera / Auditoría de Cuentas Médicas, no
programadores.

## Reglas del proyecto
- Nunca commitear usuarios ni contraseñas: solo en variables de entorno.
- Antes de un envío masivo, siempre correr un piloto pequeño.
- Mantener en verde el formateo/chequeo de código (`ruff`) en los archivos que se toquen.
