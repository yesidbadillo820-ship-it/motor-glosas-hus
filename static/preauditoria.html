Pre-auditoría — el consolidado como base de datos

← Motor de Glosas

Alimentar las fuentes

Sube periódicamente los dos reportes de Dinámica Gerencial. El sistema los usa como base para armar el consolidado. Al re-subir un archivo corregido, los datos se actualizan solos (no se duplican) y el consolidado lo refleja automáticamente.

1 Radicación de Cuentas

Dice, por factura, en qué envío va y trae F_RECIBIDO, F_FACTURA, VALOR, NIT y ENTIDAD.

2 Formato Facturación Electrónica

Facturas que tuvieron correo de factura electrónica → columna CORREO F.E. (SI/NO). Sin este soporte, la factura solo puede devolverse.

🧹 Zona de administración

Borra todos los datos del módulo (oficios, facturas, historial, envíos y oficios de devolución) para dejar la página lista y empezar a trabajar de cero. Solo administradores.

3 Registrar oficio recibido

El plazo para auditar es de 3 días hábiles desde el día siguiente al recibo. Semáforo: VERDE AMARILLO ROJO VENCIDO
