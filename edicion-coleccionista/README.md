# HIJOS DEL FIRMAMENTO — Edición Coleccionista

**Yesid Pérez Badillo**

> *Una épica de grandes almas, mitología viva y el amor que lo recuerda todo*

Edición corregida y maquetada capítulo a capítulo a partir del manuscrito original
(`HIJOS_DEL_FIRMAMENTO_EDICION_COLECCIONISTA.docx`), aplicando:

1. **Limpieza y desencriptación** — eliminación de basura tipográfica de OCR (viñetas `•`,
   cruces `+`, letras `J.` sueltas, adornos `· C ·`, capitulares duplicadas) y reparación
   del fallo sistemático de codificación: `4 → q`, `w → n`, `v → r`
   (*4ue → que, Uwa → Una, amov → amor*). El fallo marca el texto que en el original
   iba en **cursiva**, de modo que cada fragmento decodificado se restaura además en itálica.
2. **Corrección técnica** — ortografía, tildes, gramática, puntuación; raya de diálogo
   española (—) con acotaciones correctamente puntuadas; reunificación de frases partidas
   por saltos de página del archivo original.
3. **Diseño "Edición Coleccionista"** — títulos en mayúsculas espaciadas y centradas,
   separadores de escena `✦ ✦ ✦`, cursivas para pensamientos íntimos y discurso recordado.
   La voz del narrador se conserva intacta: colombianismos, voseo, repeticiones deliberadas
   y frases de impacto no se tocan.
