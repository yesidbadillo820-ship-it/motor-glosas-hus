# Sugerencias

Pestaña del menú: `admin-sugerencias` · Rutas reales: `POST /sugerencias · GET /admin/sugerencias`

**BOTÓN:** Sugerencias
**OBJETIVO:** Que solo el admin vea el panel
**DATOS NECESARIOS:** Un AUDITOR y un SUPER_ADMIN
**ARCHIVOS NECESARIOS:** Ninguno
**ACCIÓN EXACTA:** Entrar con cada rol
**RESULTADO ESPERADO:** El AUDITOR puede enviar pero no ver el panel de administración
**ERROR QUE DEBEMOS BUSCAR:** Que el AUDITOR vea sugerencias de otros
